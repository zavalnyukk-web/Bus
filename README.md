# Сайт «Шкільний автобус»: що в цій папці

Файли для репозиторію Bus на GitHub (завантажити всі, крім цього README і FIREBASE-RULES.txt):
- index.html: сторінка для батьків
- driver.html: сторінка для вихователя (передача місця з телефона)
- config.js: адреса бази й ключ (не змінювати, вже заповнений у вашому репозиторії, тож цей файл завантажувати не треба)
- manifest.webmanifest, sw.js, icon-192.png, icon-512.png: щоб сайт можна було додати на головний екран

Нові правила Firebase: див. FIREBASE-RULES.txt (вставити у вкладку Rules і натиснути Publish).
